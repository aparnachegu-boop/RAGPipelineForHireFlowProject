# RAGPipelineForHireFlowProject
HireFlow Project built using RAG pipeline

HireFlow project helps to shortlist CVs based on Job Description provided.

User can upload his CV which gets stored in Pinecone Vector Database.

User can give JD and Search for string ,RAG pipeline built fetches related jobs based on string provided and displays the list.


TechStack used : Python,GEMINI API,Streamlit
